# Adaptive Quest — An Inclusive 3D Adventure Game

A Unity 6 mini-game demonstrating accessible and inclusive gameplay through adaptive accessibility features.

## Features
- **Level 1:** Collect the Access Crystal and unlock the exit.
- **Level 2:** Solve a sequence-memory puzzle using eight coloured cards.
- **Visual Assistance:** Highlights important interactive objects.
- **Simplified Controls:** Provides alternative keyboard interactions.
- **Saved Preferences:** Remembers accessibility settings across sessions.

## Tech Stack
- C#
- Unity 6
- Unity UI, Input System, Physics and Raycasting

## Objective
Promote inclusive gaming and support **SDG 10 — Reduced Inequalities** through accessible gameplay.

## Getting Started
1. Clone this repository.
2. Open Unity Hub and select the project folder.
3. Open the project using a compatible Unity Editor version.
4. Open the main scene and press **Play**.
